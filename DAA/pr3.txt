3. Fractional Knapsack Using Greedy Method



Java Program

import java.util.Arrays;
import java.util.Scanner;

public class Main {

    static class Item {
        int weight;
        int profit;
        double ratio;

        Item(int weight, int profit) {
            this.weight = weight;
            this.profit = profit;
            this.ratio = (double) profit / weight;
        }
    }

    public static void main(String[] args) {

        Scanner sc = new Scanner(System.in);

        System.out.print("Enter number of items: ");
        int n = sc.nextInt();

        Item[] items = new Item[n];

        for (int i = 0; i < n; i++) {

            System.out.print("Enter weight and profit: ");

            int w = sc.nextInt();
            int p = sc.nextInt();

            items[i] = new Item(w, p);
        }

        System.out.print("Enter knapsack capacity: ");
        int capacity = sc.nextInt();

        // Sort according to profit/weight ratio
        Arrays.sort(items, (a, b) ->
            Double.compare(b.ratio, a.ratio)
        );

        double totalProfit = 0;

        for (int i = 0; i < n; i++) {

            if (capacity == 0)
                break;

            if (items[i].weight <= capacity) {

                totalProfit += items[i].profit;

                capacity -= items[i].weight;

            } else {

                double fraction =
                    (double) capacity / items[i].weight;

                totalProfit += items[i].profit * fraction;

                capacity = 0;
            }
        }

        System.out.println("Maximum Profit = " + totalProfit);

        sc.close();
    }
}

Aim
Write a Java program to solve the Fractional Knapsack problem using a greedy method.
Explanation
The Fractional Knapsack problem is an optimization problem in which we have a knapsack with limited capacity and several items having different weights and profits.

The objective is to maximize the total profit without exceeding the knapsack capacity.

In this method, we can take:
- A complete item.
- A fraction of an item.
Greedy Strategy: Select items according to the highest profit-to-weight ratio.
\[
Ratio = \frac{Profit}{Weight}
\]

Algorithm
1. Start.
2. Read the number of items.
3. Read the weight and profit of each item.
4. Calculate the profit-to-weight ratio for each item.
5. Sort items in descending order of ratio.
6. Initialize total profit = 0.
7. Select items one by one:
   - If the item fits completely, take the entire item.
   - Otherwise, take the required fraction of the item.
8. Add the corresponding profit.
9. Display maximum profit.
10. Stop.



Explanation of Output
Item	Weight	Profit	Ratio
1	10	60	6
2	20	100	5
3	30	120	4

Knapsack capacity = 50.
- Select item 1 completely: Profit = 60.
- Select item 2 completely: Profit = 100.
- Select 20/30 fraction of item 3: Profit = 80.
Therefore:
\[
Maximum\ Profit = 60+100+80=240
\]

Time and Space Complexity
Operation	Complexity
Calculating ratios	O(n)
Sorting items	O(n log n)
Selecting items	O(n)
Total Time	O(n log n)
Space	O(n)

Conclusion: Fractional Knapsack uses a greedy strategy to maximize profit by selecting items with the highest profit-to-weight ratio.
