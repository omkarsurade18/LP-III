2. Huffman Encoding Using Greedy Strategy



Java Program

import java.util.PriorityQueue;

public class Main {

    static class Node {
        char ch;
        int freq;
        Node left, right;

        Node(char ch, int freq) {
            this.ch = ch;
            this.freq = freq;
        }
    }

    static void printCodes(Node root, String code) {

        if (root == null)
            return;

        if (root.left == null && root.right == null) {
            System.out.println(root.ch + " : " + code);
            return;
        }

        printCodes(root.left, code + "0");
        printCodes(root.right, code + "1");
    }

    public static void main(String[] args) {

        char[] chars = {'A', 'B', 'C', 'D', 'E', 'F'};
        int[] freq = {5, 9, 12, 13, 16, 45};

        PriorityQueue<Node> pq = new PriorityQueue<>(
            (a, b) -> Integer.compare(a.freq, b.freq)
        );

        for (int i = 0; i < chars.length; i++) {
            pq.add(new Node(chars[i], freq[i]));
        }

        while (pq.size() > 1) {

            Node left = pq.poll();
            Node right = pq.poll();

            Node parent = new Node(
                '\0', left.freq + right.freq
            );

            parent.left = left;
            parent.right = right;

            pq.add(parent);
        }

        Node root = pq.poll();

        System.out.println("Huffman Codes:");
        printCodes(root, "");
    }
}

Aim
Write a Java program to implement Huffman Encoding using a greedy strategy.
Explanation
Huffman Encoding is a lossless data compression technique.

It assigns:
- Shorter binary codes to frequently occurring characters.
- Longer binary codes to less frequently occurring characters.
It uses a greedy approach by repeatedly selecting the two nodes having the smallest frequencies and combining them into a new node.

Example:
Character	Frequency
A	5
B	9
C	12
D	13
E	16
F	45

Algorithm
1. Start.
2. Create a leaf node for each character with its frequency.
3. Insert all nodes into a priority queue.
4. Remove the two nodes having the minimum frequencies.
5. Create a new internal node with frequency equal to their sum.
6. Make the two removed nodes its left and right children.
7. Insert the new node into the priority queue.
8. Repeat until only one node remains.
9. Traverse the Huffman tree:
   - Assign 0 to the left branch.
   - Assign 1 to the right branch.
10. Display the Huffman codes.
11. Stop.


Note: Huffman codes can differ depending on how equal frequencies are handled. The above is one valid result.
Time and Space Complexity
Let n be the number of distinct characters.
Operation	Complexity
Creating priority queue	O(n)
Building Huffman Tree	O(n log n)
Generating codes	O(n)
Total Time	O(n log n)
Space	O(n)

Conclusion: Huffman Encoding reduces storage requirements by assigning variable-length binary codes based on character frequencies.
