5. N-Queens Problem Using Backtracking

Java Program

import java.util.Scanner;

public class Main {

    static int N;

    // Check whether Queen can be placed safely
    static boolean isSafe(int board[][], int row, int col) {

        // Check column
        for (int i = 0; i < row; i++) {
            if (board[i][col] == 1)
                return false;
        }

        // Check upper-left diagonal
        for (int i = row - 1, j = col - 1;
             i >= 0 && j >= 0; i--, j--) {

            if (board[i][j] == 1)
                return false;
        }

        // Check upper-right diagonal
        for (int i = row - 1, j = col + 1;
             i >= 0 && j < N; i--, j++) {

            if (board[i][j] == 1)
                return false;
        }

        return true;
    }

    // Backtracking
    static boolean solve(int board[][], int row) {

        if (row == N)
            return true;

        for (int col = 0; col < N; col++) {

            if (isSafe(board, row, col)) {

                board[row][col] = 1;

                if (solve(board, row + 1))
                    return true;

                // Backtrack
                board[row][col] = 0;
            }
        }

        return false;
    }

    public static void main(String[] args) {

        Scanner sc = new Scanner(System.in);

        System.out.print("Enter value of N: ");
        N = sc.nextInt();

        if (N <= 0) {
            System.out.println("Invalid N");
            sc.close();
            return;
        }

        int board[][] = new int[N][N];

        boolean found = false;

        // Try first Queen in every column
        for (int col = 0; col < N; col++) {

            board[0][col] = 1;

            if (solve(board, 1)) {
                found = true;
                break;
            }

            board[0][col] = 0;
        }

        if (found) {

            System.out.println("N-Queens Solution:");

            for (int i = 0; i < N; i++) {

                for (int j = 0; j < N; j++) {
                    System.out.print(board[i][j] + " ");
                }

                System.out.println();
            }

        } else {
            System.out.println("Solution does not exist.");
        }

        sc.close();
    }
}

Aim
Write a Java program to design an N-Queens matrix having the first Queen placed and use backtracking to place the remaining Queens to generate the final N-Queens matrix.
Explanation
The N-Queens problem is a classic backtracking problem.

The objective is to place N Queens on an N × N chessboard so that no two Queens attack each other.

Rules:
1. No two Queens should be in the same row.
2. No two Queens should be in the same column.
3. No two Queens should be on the same diagonal.
Backtracking: It places a Queen in a safe position. If no safe position is available, it goes back to the previous position and tries another position.

In this program, the first Queen is fixed at row 0, column 0.
Algorithm
1. Start.
2. Create an N × N chessboard and initialize all positions to 0.
3. Place the first Queen at position [0][0].
4. Start placing Queens from the second row.
5. Check whether the current position is safe:
   - Check the same column.
   - Check the upper-left diagonal.
   - Check the upper-right diagonal.
6. If the position is safe, place the Queen.
7. Recursively place the next Queen.
8. If placement fails, remove the Queen and try another column.
9. If all Queens are placed successfully, display the chessboard.
10. Stop.


The program generates a valid arrangement; the second matrix above is the expected valid arrangement for this fixed first Queen.
Time and Space Complexity
Complexity	Value
Time Complexity	O(N!) (upper-bound search estimate)
Space Complexity	O(N²) for board and O(N) recursion stack

Conclusion: The N-Queens problem uses backtracking to find a valid arrangement of Queens on a chessboard without attacking each other.
